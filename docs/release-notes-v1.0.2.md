## 一键隐藏 / 恢复指定程序窗口

WinHide 是一个约 60 KB 的单文件 Windows 小工具：把选定的程序窗口从屏幕和任务栏隐藏起来，再按一下原样恢复。**只隐藏窗口，不结束进程**，所以不丢进度、不丢登录态。

### 这个版本

- 托盘常驻，`Ctrl+Alt+H` 隐藏、`Ctrl+Alt+R` 恢复（可在托盘菜单里重新录制任意组合键）
- 支持**同键切换**：只用一个热键，按一次藏、再按一次回来
- 目标程序在界面里勾选，也可手写「进程名|标题关键字」
- 隐藏时记录窗口句柄，恢复只还原自己藏过的窗口，不会把程序内部的隐藏窗口弹出来
- 自动排除输入法窗口、托盘消息窗、桌面窗口等系统辅助窗口
- 按进程 PID 过滤窗口，单次操作约 2～3 ms
- 图标、DPI 清单、版本信息全部编译进单个 exe

### 安装 / 使用

下载下面的 `WinHide-1.0.2.zip`，解压双击 `WinHide.exe` 即可，无需安装。

第一次启动后：托盘图标右键 →「选择目标程序…」→ 勾选要管理的窗口 → 确定。

### 系统要求

- Windows 7 / 8 / 8.1 / 10 / 11（32 位、64 位均可）
- .NET Framework 4.x（Win10/11 自带 4.8；Win7 需自行安装）

### 注意

- 程序未做代码签名，首次运行可能被 SmartScreen 拦一次：点「更多信息 → 仍要运行」。
- 要操作以管理员身份运行的程序时，本工具也需以管理员身份启动。
- 只隐藏不退出进程，真正退出请用程序自身的退出功能。
