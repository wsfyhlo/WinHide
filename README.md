# WinHide

> 一键隐藏 / 恢复指定程序窗口。像"老板键"，但只针对你选中的程序，进程不退出、进度不丢。

Windows 上一个约 60 KB 的单文件小工具：托盘常驻，按一下热键让选定的程序窗口从屏幕和任务栏消失，再按一下原样回来。

![icon](docs/icon.png)

## 特性

- **只隐藏，不结束进程**：窗口消失但程序继续跑，内存/CPU 照常，不丢进度、不丢登录态。
- **自己选目标**：托盘右键 →「选择目标程序…」，从当前窗口列表里勾选，也支持手写进程名 + 标题关键字。
- **热键可改**：托盘菜单「设置热键…」，点进输入框直接按组合键即可录制，立即生效。
- **同键切换**：可以只用一个热键——按一次藏、再按一次回来。
- **不会误伤系统窗口**：自动排除输入法窗口、托盘消息窗、桌面窗口等辅助窗口。
- **恢复只还原自己藏过的窗口**：隐藏时记录句柄，恢复时按记录还原，不会把程序内部的隐藏窗口弹出来。
- **免安装、无依赖**：单文件 exe，不需要 .NET SDK，不写系统目录，配置放在 `%APPDATA%\WinHide`。
- **毫秒级响应**：按进程 PID 反查窗口，不做逐窗口的进程对象创建，实测单次 2～3 ms。
- **原生图标与高 DPI**：多尺寸图标、系统级 DPI 感知清单、带版本信息。

## 快速开始

### 方式一：下载现成的 exe

到 [Releases](../../releases) 下载 `WinHide-x.y.z.zip`，解压后双击 `WinHide.exe`。

### 方式二：自己编译

仓库里不含二进制产物，只保留源码。编译只需要 Windows 自带的 csc：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物在 `dist\WinHide.exe`。

## 使用

1. 双击 `WinHide.exe`，托盘出现蓝色图标（可能在任务栏右下角的 `^` 折叠区）。
2. 右键图标 → **选择目标程序…** → 勾选要管理的窗口 → 确定。
3. `Ctrl+Alt+H` 隐藏，`Ctrl+Alt+R` 恢复；或改成你要的键，或启用同键切换。

| 操作 | 方式 |
|---|---|
| 隐藏目标 | 热键 / 托盘菜单「隐藏目标窗口」/ 双击托盘图标 |
| 恢复目标 | 热键 / 托盘菜单「恢复目标窗口」 |
| 改热键 | 托盘菜单「设置热键…」 |
| 同键切换 | 托盘菜单「隐藏/恢复同键切换」 |
| 改目标 | 托盘菜单「选择目标程序…」或「编辑目标列表」 |
| 开机自启 | 托盘菜单「开机自动启动」（写入 HKCU\Run） |

## 配置文件

都在 `%APPDATA%\WinHide\` 下，**每个 Windows 账号独立**：

| 文件 | 作用 |
|---|---|
| `targets.txt` | 目标程序列表 |
| `hotkeys.txt` | 热键配置 |
| `hidden.txt` | 隐藏状态记录（自动维护） |
| `winhide.log` | 运行日志，含每次操作耗时 |

`targets.txt` 格式：

```
# 每行一个目标：进程名|窗口标题关键字
# 标题留空 = 该进程的所有窗口
chrome.exe|
QQMusic.exe|周杰伦
```

`hotkeys.txt` 格式：

```
hide=Ctrl+Alt+H
show=Ctrl+Alt+R
samekey=0        # 改成 1 即隐藏/恢复共用一个热键
```

- 进程名大小写不限，带不带 `.exe` 都行；标题是「包含」匹配。
- 手改配置文件后需重启程序；用托盘菜单改则即时生效。
- 支持按键：`A`–`Z`、`0`–`9`、`F1`–`F24`、`Space`、`Tab`、`Enter`、`Esc`、`Backspace`、`Delete`、`Insert`、`Home`、`End`、`PageUp`、`PageDown`、`Up`、`Down`、`Left`、`Right`。

便携用法：用环境变量把配置放到 exe 同目录。

```bat
set WINHIDE_CONFIG=D:\Tools\WinHide\targets.txt
set WINHIDE_HOTKEYS=D:\Tools\WinHide\hotkeys.txt
WinHide.exe
```

## 常见问题

**首次运行被 SmartScreen 拦了？**
程序未做代码签名，通过浏览器/聊天软件下载的文件会带"来自网络"标记。点「更多信息 → 仍要运行」即可，或者用 `Unblock-File` 解除。

**杀毒软件报可疑？**
这类"操作其他程序窗口"的行为容易触发启发式判断。项目不注入进程、不读写目标程序内存、不联网、不落地额外文件，源码全部可见，可自行审计后加白。

**某些程序藏不掉？**
目标以管理员身份运行时，Windows 的 UIPI 会拒绝对它的窗口操作。此时右键本工具「以管理员身份运行」即可。程序会校验操作结果，失败时会提示而不是假装成功。

**热键没反应？**
热键可能被其他程序占用了。程序注册失败时会弹提示并保留原有热键，换一个组合即可。

**重启电脑后目标还在，但热键要改？**
配置是持久化的，开机自启只是把程序拉起来，目标与热键都会沿用。

## 已知限制

- 只隐藏窗口，不结束进程。要真正退出请用程序自身的退出功能。
- 带反作弊/防截屏的程序可能检测到窗口被隐藏并自行退出，这类程序不适合本工具。
- 界面目前只有中文（代码里的文案，欢迎 PR 做多语言）。

## 实现要点

- 隐藏：`ShowWindow(hwnd, SW_HIDE)`，只处理目标进程的可见窗口，并跳过输入法/托盘等辅助窗口。
- 恢复：优先按 `hidden.txt` 里记录的句柄还原（校验句柄仍属原进程，避免句柄复用误伤）；记录缺失时只还原进程主窗口。
- 目标定位：`Process.GetProcessesByName` 先拿 PID 集合，再 `EnumWindows` 只比对 PID，避免为每个窗口创建进程对象。
- 热键：`RegisterHotKey` + 隐藏窗体接收 `WM_HOTKEY`；注册失败自动回滚到旧热键。
